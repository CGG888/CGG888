为什么只有两件

关于「不把仓库全弄上去」

我的 GitHub 上有一百多个仓库。如果把它们全铺在这个页面上，你会看到一片灰色——因为我确实 fork 了很多东西：路由器固件、媒体库、面板、订阅转换、一堆我某天凌晨觉得「这个我得看看」的项目。

它们都是真的，也都对我有用。但它们不是我的作品。一本书架不该假装自己写的每一本书。

还要先说清一件事：主业是币圈的技术支持与服务，那不在这里。那些东西没有仓库、没有截图，也不该出现在一个个人作品页上。工作用来吃饭，作品用来证明我还没把自己整个交出去。

所以我做了个很粗暴的决定：只有置顶的才配出现在这个页面上。置顶是我自己在 GitHub 上点的，不是算法给的。我想挂两件，就只有两件。

如果你真的想看我都在折腾什么，直接去 GitHub 翻——那里是全部，包括那些半途而废的。这里只是门口。
