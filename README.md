## 我信什么

| | |
|---|---|
| **一** | 数据应该待在自己的硬盘上 |
| **二** | 工具应该在断网的那一刻还活着 |
| **三** | 每个功能都要能回答「为什么」 |
| **四** | 工具不要求你注册账号 |
| **五** | 新的东西，必须自己摸一遍 |

> 如果一个工具在断网的那一刻就死了，那它其实不属于你。

---

## 现在在做什么

- 把 **SrcBox** 做成一个不需要说明书的东西
- 让每一路信号都能被看见、被记录、被回溯
- 把「搬回自己家」做成一套能复用的东西：反代、内网穿透、媒体库、监控
- 把阳台也接进来：自动浇水、光照记录、一株菜从种子到上桌的完整日志

一棵菜和一路信号，本质上是同一个问题：**都得自己盯着。**
